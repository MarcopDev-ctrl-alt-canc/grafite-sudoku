Where to start

Look at row 2, column 3: only one number fits there.

The rules

Every row, every column and every 3×3 box must contain the numbers 1 to 9, each exactly once.

Tips for solving it

  • Use a pen or a soft pencil: the big cells leave room for pencil marks too.
  • Start with the boxes that have the most numbers: they have few free spots left.
  • For each number missing from a row, check the columns: often it has only one place.
